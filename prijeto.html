🚀 Projeto Flask + Docker

✔️ Criei uma aplicação simples usando Flask em Python.

✔️ Montei um Dockerfile para empacotar essa aplicação.

✔️ Construí a imagem com o Docker.

✔️ Rodei o container mapeando a porta 5000.

✔️ A aplicação rodou com sucesso dentro do container, acessível pelo navegador na porta 5000.
